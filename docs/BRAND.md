# Praxis visual identity

The Praxis identity uses a folded ribbon symbol, a geometric wordmark and the following palette. These colors are the agreed reference for the future dashboard; this documentation update does not change the current application theme.

| Token         | Color     | Role                                    |
| ------------- | --------- | --------------------------------------- |
| Charcoal      | `#0F172A` | Wordmark, dark surfaces and primary ink |
| Electric Blue | `#2563EB` | Brand accent and primary actions        |
| Light         | `#F8FAFC` | Light surfaces and inverse mark         |

The ribbon includes a blue-to-cyan gradient. Cyan is a secondary accent within the mark, not an additional primary palette color. Retain the upper fold, ascending central ribbon and separated triangular lower fold together.

## Assets

- [Primary mark](assets/brand/praxis-primary.png): symbol and Praxis wordmark together.
- [Icon variant](assets/brand/praxis-icon.png): isolated ribbon symbol; also available as [SVG](assets/brand/praxis-icon.svg).
- [Wordmark](assets/brand/praxis-wordmark.png): Praxis lettering without the symbol.
- App icon: ribbon on a rounded square, with [light](assets/brand/praxis-app-icon-light.png) and [dark](assets/brand/praxis-app-icon-dark.png) variants.

The files live under `docs/assets/brand/`. Transparent masters are suitable for composition; choose a variant with sufficient contrast against the background. The architecture illustration uses an inverse ribbon on its dark background.

Use this identity when designing the dashboard. Preserve readable text, keyboard focus and sufficient contrast in interactive states rather than applying the brand blue to every surface.
